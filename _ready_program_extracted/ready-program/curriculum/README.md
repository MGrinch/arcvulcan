# Curriculum Grounding (Local)

This folder holds **local grounding sources** that the Tutor can cite.

## Structure
- `manifest.json` lists sources (id/title/path/tags/license)
- `sources/` contains the actual texts (`.md` or `.txt`)

## Legal note
Only place content here that you have the rights to use (public domain,
open-license, or your own notes).
