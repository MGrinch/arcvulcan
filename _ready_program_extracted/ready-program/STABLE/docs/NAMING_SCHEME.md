# NAMING_SCHEME.md (STABLE)

This repo uses **release names** that are **1–2 words** and always feel like:
**welding-first**, with a **sacred/cosmic fantasy** overtone.

## Canonical formula

### Option A — One word (preferred)
`<WeldRoot><SacredCosmicRoot>` in CamelCase.

Examples:
- ForgeHalo
- ForgeSeraph
- ArcEmpyrean
- AnvilAether
- ForgeRevelation
- ArcVulcan

### Option B — Two words (allowed)
`WeldRoot SacredCosmicRoot`

Examples:
- Anvil Empyrean
- Arc Empyrean
- Anvil Halo

## Root pools

### WeldRoot (must come first)
Pick one:
- Arc, Weld, Forge, Anvil, Crucible, Foundry, Hammer, Tongs, Flux, Bead, Seam, Quench, Temper, Slag, Spark

### SacredCosmicRoot (cosmology + faith + fantasy)
Pick one:
- Halo, Firmament, Empyrean, Aether, Seraph, Covenant, Reliquary, Sanctum, Genesis, Eclipse, Nebula, Quasar, Oracle, Ark, Starborn, Astral, Eschaton

## Constraints (hard rules)
- **Keep it 1–2 words.**
- **WeldRoot must be first** (welding is the primary identity).
- Avoid names that are primarily “space” with a tiny welding hint.
- Avoid real-world denominational claims (keep it mythic / symbolic).
- Prefer **distinct** roots across versions (no repeats back-to-back).

## Versioning
- Numeric version remains: `vN` (not part of the name).
- Each release gets a new name by swapping at least one root.

Current release name: **ArcVulcan**.
